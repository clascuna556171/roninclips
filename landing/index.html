[INSTALL]

Up and running in 60 seconds.

RECOMMENDED

Windows One-Click

cmd 
git clone https://github.com/clascuna556171/roninclips.git
cd roninclips
setup.bat

Then double-click start.bat → open http://127.0.0.1:8000

PowerShell One-Liner

powershell 
iwr -useb https://raw.githubusercontent.com/clascuna556171/roninclips/main/install.ps1 | iex

Manual (macOS / Linux)

bash 
git clone https://github.com/clascuna556171/roninclips.git
cd roninclips && cp .env.example .env
php artisan key:generate
composer install && pip install -r processor/requirements.txt
php artisan migrate && php artisan serve
